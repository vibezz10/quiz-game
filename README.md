# JavaScript Quiz App

A responsive, browser-based multiple-choice quiz built with plain HTML, CSS, and JavaScript.

## Features

- Five JavaScript and web-development questions
- Answer selection with instant correct/incorrect feedback
- Progress bar and live score display
- Final score and restart option
- Responsive layout for mobile and desktop

## Run locally

Clone or download the repository, then open `index.html` in any modern web browser. No installation or build tools are required.

## Project structure

```
├── index.html   # Page structure
├── style.css    # Responsive visual design
└── script.js    # Quiz questions and interaction logic
```

## Publish with GitHub Pages

1. Push these files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and the `/(root)` folder, then save.
4. GitHub will provide the public site URL after deployment.
